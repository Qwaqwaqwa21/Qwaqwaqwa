# LAS inventory

Скрипт `las_inventory.py` строит каталог LAS-файлов по структуре вида

```
<root>/ГИС_1/1_Ромашкинское/<горизонт>/*.las
<root>/ГИС_1/1_Ромашкинское/INKl/*.las
<root>/ГИС_2/2_Бавлинское/...
```

и сохраняет в Excel таблицу с колонкой `well_field` в формате
`<номер_скважины>_<название_месторождения>` (например `5162_Ромашкинское`,
ведущий `1_` из имени папки месторождения отбрасывается).

Скрипт не открывает содержимое LAS-файлов, а только перечисляет имена
файлов и папок через файловую систему — это делает его быстрым независимо
от объёма данных (в т.ч. на деревьях в сотни гигабайт), так как время
работы зависит от количества файлов, а не от их размера. Кодировка
содержимого LAS-файлов (cp1251/utf-8/ibm866) на результат не влияет, т.к.
имена файлов и папок читаются напрямую операционной системой.

Полные дубликаты (одинаковая пара номер скважины + месторождение,
например когда одна и та же скважина встречается в нескольких горизонтах
или в папке `INKl`) удаляются, остаётся одна строка.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```bash
python3 las_inventory.py /path/to/root -o las_inventory.xlsx
```

Параметры:

- `root` — корневая папка со структурой `ГИС_N/N_Месторождение/...` (обязательный)
- `-o, --output` — путь к результирующему `.xlsx` (по умолчанию `las_inventory.xlsx`)
- `-w, --workers` — число потоков для параллельного сканирования папок
  (по умолчанию подбирается по числу CPU); сканирование запускается
  параллельно по папкам `ГИС_N`, что ускоряет обход на сетевых дисках
- `-v, --verbose` — подробный лог

Если результат превышает лимит листа Excel (1 048 576 строк), рядом с
`.xlsx` дополнительно сохраняется полный `.csv`.

## Результирующие колонки

| Колонка | Описание |
|---|---|
| `well_field` | Итоговый формат: `номер_скважины_название_месторождения` |
| `well_number` | Номер скважины (имя LAS-файла без расширения) |
| `field_name` | Название месторождения без ведущего `N_` |
| `gis_batch` | Папка верхнего уровня (`ГИС_1`, `ГИС_2`, ...) |
| `field_folder` | Исходное имя папки месторождения (`1_Ромашкинское`) |
| `category` | `инклинометрия`, если файл лежит в папке `INKl`, иначе `горизонт/прочее` |
| `relative_path` | Путь к файлу относительно `root` |
