# Петрофизическая вики (Petrophysics Wiki)

Внутренняя база знаний по промысловой геофизике (ГИС) и петрофизической
интерпретации — с историей версий и ролевым доступом на чтение/редактирование.

**Это отдельный, самостоятельный сайт.** Он не импортирует и не зависит ни от
кода, ни от базы данных GeoLog (`../backend`, `../frontend`) — свой FastAPI-сервер,
своя SQLite-база, свой Docker-образ, свой порт (`8010` вместо `8000` у GeoLog).
Каталог `wiki/` можно скопировать или вынести в отдельный git-репозиторий без
каких-либо изменений в коде.

## Запуск

### Docker (рекомендуется)

```sh
cd wiki
docker compose up --build
```

Сайт будет доступен на http://localhost:8010

### Локально (без Docker)

```sh
cd wiki
pip install -r requirements.txt
python run.py
```

## Роли

Ролевая модель определена только внутри этого приложения (заголовок `X-Role`,
выбирается в интерфейсе) и никак не связана с системой ролей GeoLog:

- **Читатель (viewer)** — только просмотр страниц.
- **Редактор (editor)** — создание и редактирование страниц, откат версий.
- **Администратор (admin)** — то же, что редактор, плюс удаление страниц.

Каждое сохранение страницы создаёт запись в истории версий (`История` на
странице статьи), с возможностью просмотра и отката к любой предыдущей версии.

## API

- `GET  /api/pages` — список страниц (`?q=` поиск, `?category=` фильтр)
- `GET  /api/pages/{slug}` — содержимое страницы
- `POST /api/pages` — создать страницу (роль: editor+)
- `PUT  /api/pages/{slug}` — изменить страницу (роль: editor+)
- `DELETE /api/pages/{slug}` — удалить страницу (роль: admin)
- `GET  /api/pages/{slug}/history` — список версий
- `GET  /api/pages/{slug}/history/{id}` — содержимое версии
- `POST /api/pages/{slug}/revert/{id}` — откат к версии (роль: editor+)
- `GET  /api/categories` — список категорий
- `GET  /api/health` — проверка живости
