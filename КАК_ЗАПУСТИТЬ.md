# GeoLog — как запустить на своём компьютере

Приложение = Python-бэкенд (FastAPI) + статический фронтенд. База данных — SQLite
(файл создаётся автоматически, ставить ничего не нужно).

## Требования
- **Python 3.10 – 3.13**, рекомендуется **3.12** (проверить: `python --version`).
  Проверено на 3.11 и 3.13. На самом свежем 3.14 часть библиотек ещё не имеет
  готовых сборок под Windows и pip пытается компилировать их из исходников —
  если увидите ошибку про `numpy` и `meson`, поставьте 3.12.
- Интернет нужен только для установки зависимостей — само приложение работает
  локально и офлайн.

---

## Запуск в один шаг (проще всего)

- **Windows** — положите `start.bat` в папку с `run.py` и запустите двойным
  кликом. Скрипт сам найдёт подходящий Python, создаст `.venv`, поставит
  зависимости (только при первом запуске) и откроет браузер.
- **macOS / Linux** — `./start.sh` (другой порт: `./start.sh 8001`).

---

## Запуск вручную

### 1. Распаковать архив
Распакуйте `geolog.zip` в любую папку и откройте её в терминале.

### 2. Виртуальное окружение и зависимости

**Windows (cmd или PowerShell):** обратите внимание — слэши **обратные**,
`source` на Windows не существует.
```
py -3.12 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
После активации строка приглашения начинается с `(.venv)`.

**macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Запустить сервер (из корня распакованной папки)
```bash
python run.py
```
Порт по умолчанию 8000. Другой порт: `python run.py 8001`.

### 4. Открыть в браузере
```
http://127.0.0.1:8000
```
Остановить — `Ctrl+C` в терминале.

При первом запуске автоматически создаётся проект «My Project» — можно сразу
загружать данные.

### Вариант через Docker
```bash
docker compose up --build
```

## Порядок работы с данными

1. **Загрузка каротажа** — кнопка **Upload LAS** (один файл) или **Bulk Import**
   (много файлов; кнопка **Select Folder** берёт папку рекурсивно, вместе с
   подпапками). Читаются UTF-8, CP1251 и CP866 — русские мнемоники и имена
   скважин распознаются автоматически.
2. **Отбивки (горизонты)** — загружаются на скважину; нужны для карт по
   горизонтам и таблицы охвата.
3. **Координаты** — вкладка **Карты** → **Импорт координат**: Excel или CSV с
   колонками `Скважина | X | Y | Альтитуда` (русские и английские заголовки).

## Где что находится

**Analysis → Coverage** — карта охвата ГИС:
- *Матрица* — скважина × метод;
- *Планшет по глубине* — закрашенные столбцы по глубине, горизонты, жёлтая
  штриховка = метод записан в двух рейсах (повтор);
- *Таблица по горизонтам* — с экспортом в XLSX/CSV.

**Analysis → Mnemonics** — авто-нормализация мнемоник (ГК→GK, НГК→NGK, КС→KS,
БКЗ/ГЗ1-5, МКЗ, АК, ГГКп, ЯМК и т.д.) плюс свои алиасы: ручной ввод, импорт из
Excel/CSV, просмотр встроенных умолчаний.

**Инклинометрия** — DLS с настраиваемым порогом (по умолчанию 20°/10 м),
вертикальная проекция, план, профиль DLS; удаление дублей замеров; заметки по
качеству (авто по QC и вручную).

**Карты** — карта устьев, альтитуды, толщина коллектора, пористость
(среднегармоническая), нефтенасыщенная толщина. Палитры physics и physics
reverse, изолинии с подписями, легенда на каждой карте.
- **CLIPBOARD** в левой панели под списком скважин — библиотека карт по папкам
  (Пористость / Нефтенасыщенность / Толщины / Прочее). Кнопка «В clipboard»
  сохраняет текущую карту, клик по позиции — открывает её.
- В режиме карт **клик по скважине в списке** исключает её из интерполяции
  (помечается «вне сетки»), карта пересчитывается.
- Кнопка **«Что есть в скважинах»** — таблица наличия координат, альтитуды,
  инклинометрии, методов ГИС, РИГИС, отбивок.

**Планшет каротажа** — колонки РИГИС: литология условной штриховкой (известняк —
кирпич, песчаник — точки, глина — линии), коллектор и насыщение; при наведении
у курсора выводится русская расшифровка кода.

## Частые вопросы
- **Порт занят** — `python run.py 8001`, открывать `http://127.0.0.1:8001`.
- **На Windows не находится `python`** — используйте `py`.
- **Не активируется venv в PowerShell** — один раз выполните
  `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, затем повторите.
- **Сбросить все данные** — удалите файл `backend/geolog.db` и перезапустите.
- **Кнопки не реагируют** — обновите страницу с очисткой кэша (Ctrl+F5).
- **Загрузка отклоняется (403)** — в правом верхнем углу переключите роль на
  Admin или Interpreter (Viewer только читает).
